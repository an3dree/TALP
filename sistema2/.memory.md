# Comandos do Sistema

## Backend
- `npm run dev` - Executa servidor em modo desenvolvimento (ts-node-dev)
- `npm run build` - Compila TypeScript para JavaScript (dist/)
- `npm start` - Executa servidor compilado

## Frontend
- `npm run dev` - Executa aplicação React em modo desenvolvimento
- `npm run build` - Compila para produção
- `npm run preview` - Preview da build de produção
